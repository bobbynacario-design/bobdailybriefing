# Working questions

Open Research → Questions & Evidence. Create a named set or select an existing one, enter the question and its purpose, and save it. Search terms drive Find evidence; use a short topic rather than a full sentence for broader results. Save search results into the same set.

Keep your assessment and unresolved evidence requests in their own fields. A target date and Active/Closed status help distinguish ongoing work. Mark evidence reviewed records a checkpoint; the counter measures saved items added after that checkpoint, not newly published articles or automatic monitoring.

Export research note downloads Markdown and displays a copyable version. It separates personal assessment from saved excerpts, with source labels, capture dates, and app references. Excerpts are compact snapshots, not verified quotations. Open source remains the route to the original record.

Questions use the existing account-scoped evidence document and transactional conflict handling. Unsaved form drafts survive in-app selection changes during the session; save before closing the app. Signing out clears session drafts. Existing sets remain valid without a question. No additional model calls, background jobs, or database rules are required.

Validation: full test suite; legacy normalization, question round trips, export structure, and simultaneous question/evidence edits; browser fixture covering create, save, search, attach evidence, review checkpoint, export preview, and draft preservation. The fixture does not write production data.
